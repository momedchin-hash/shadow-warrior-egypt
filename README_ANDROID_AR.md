# Shadow Warrior Egypt — بناء APK من الموبايل

هذا المشروع نموذج أولي ثلاثي الأبعاد يعمل دون إنترنت بعد التثبيت. الشخصيات والأعمدة أشكال بسيطة مؤقتة، وليست رسومات واقعية نهائية.

## الخطوات من متصفح الموبايل

1. أنشئ حسابًا على https://github.com ثم افتح https://github.com/new لإنشاء مستودع **Public** باسم `shadow-warrior-egypt` (لا تضف README تلقائيًا).
2. فك ضغط الملف على الموبايل. افتح المستودع في المتصفح واختر **Add file → Upload files**، ثم ارفع **محتويات** المجلد (وليس ملف ZIP). تأكد من وجود `project.godot` و`export_presets.cfg` و`scenes/` و`scripts/` و`.github/workflows/android-apk.yml` بنفس البنية. متصفح الهاتف قد لا يسمح برفع المجلدات؛ يمكن استخدام واجهة GitHub في وضع سطح المكتب أو تطبيق Git يدعم رفع المجلدات.
3. بعد حفظ الملفات على فرع `main`، افتح تبويب **Actions** واختر **Build Android APK** ثم **Run workflow**. سيبدأ البناء أيضًا تلقائيًا بعد رفع الملفات.
4. انتظر انتهاء التشغيل بعلامة خضراء. افتح نتيجة التشغيل وانزل إلى **Artifacts** واضغط `ShadowWarriorEgypt-Android-APK` لتنزيل ملف ZIP الذي يحتوي على APK.
5. فك ضغط ملف الـ Artifact، وافتح `ShadowWarriorEgypt.apk` لتثبيته. قد يطلب أندرويد السماح بالتثبيت من هذا المصدر؛ لا تثبّت إلا الملف الذي بنيته بنفسك.

## عند حدوث خطأ

من صفحة Actions افتح التشغيل الفاشل، وافتح الخطوة الحمراء واقرأ رسالة الخطأ. قد يلزم تحديث إعدادات Godot/Android إذا تغيرت أدوات GitHub أو إصدار SDK. لم يتم اختبار البناء على GitHub فعليًا هنا.

## ملاحظات

- البناء يتم على خوادم GitHub ويتطلب اتصالًا بالإنترنت، لكن اللعب بعد التثبيت أوفلاين.
- ملف APK تجريبي موقّع بمفتاح debug، وليس إصدار متجر نهائيًا.
- لا ترفع مفاتيح توقيع الإنتاج إلى مستودع عام.
